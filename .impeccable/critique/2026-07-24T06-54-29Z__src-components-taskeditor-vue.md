# Linear Lite 右侧属性区优化清单

结论：当前右栏结构可用，但视觉与交互仍像通用后台表单；参考 Linear 应改为“扁平属性行”，减少灰色输入框、重复字段名和分组边界。

## P1

1. 接通“项目”选择器，或降级为明确的只读文本；当前按钮有 hover/cursor 但没有 click 行为。
2. 在属性原位提供保存中、已保存、保存失败与重试反馈；不能只在远端顶部提示或失败后写控制台。
3. 显式说明进度与状态联动；进度到 100% 或从 100% 下调时，需就地提示状态会同步变化。

## P2

1. 将“执行 / 时间 / 归档”重组为“Properties / Labels / Project / Dates”；标签和项目不属于归档。
2. 状态、优先级、负责人、日期改为图标 + 当前值的透明属性行，hover/focus 时才显示弱底色。
3. 去掉重复的字段标签、边框、灰底和常驻下拉箭头；“设置优先级”改为“优先级”。
4. 标签使用彩色点 + 胶囊，添加操作使用行内“+”；项目使用紧凑图标 + 文本行。
5. 进度控件由整块灰框改为紧凑行，并提高滑块命中区；百分比使用等宽数字。

## P3

1. 右栏从 260px 调整为约 288–304px，避免中文日期和值局促，同时保持正文优先。
2. 字段文字不低于 12px，提升 muted 文本对比度；交互目标尽量达到 32–36px。
3. 中文标题移除 uppercase/额外字距，分隔线减量，以留白承担层级。
4. 1100px 以下不要直接把属性区堆到正文尾部，改为可折叠抽屉或顶部属性摘要。

## 保留项

- 状态、优先级、负责人已有图标和可读值。
- 日期的“今天截止”等上下文说明有业务价值。
- 当前设计已使用项目 token；检测器在右侧 `.editor-props` 范围内无直接违规命中。

启发式评分：17/40。主要风险是交互可信度、信息架构和过度表单化。
