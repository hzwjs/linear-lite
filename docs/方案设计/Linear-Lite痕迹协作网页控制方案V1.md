# Linear Lite 痕迹协作网页控制方案 V1

日期：2026-11-10。状态：方案与任务拆分，开发未开始。

采用“网页配置与控制 → 服务器保存批次 → 本机宿主领取执行”的方案。用户通过网页完成任务授权、范围与依赖配置、批次启停和状态查看，无需复制令牌或执行命令。

本方案承接《Linear-Lite痕迹协作改造方案V1》，补充网页控制、宿主授权与后台运行能力；本轮启动方式采用网页手动启动，不启用定时任务。原方案文档保留。

## 1. 用户操作流程

1. 安装本机宿主，完成账号与设备授权。
2. 在项目设置绑定本机项目根目录，查看设备连接状态。
3. 在任务详情维护执行授权、写入范围、前置依赖与完成条件。
4. 在任务列表勾选任务，点击“启动协作批次”，确认设备、目录和预算。
5. 在“协作执行”页面查看任务进度、阻塞原因、检查点与交付成果，按需停止批次。

开启任务授权表示允许执行，批次启动才发出执行意图。关闭浏览器不停止批次，刷新页面不新建批次。

## 2. 用户、项目、设备与目录

**一个用户 × 一个项目 × 一台设备对应一条项目绑定记录**，沿用 `(user_id, project_id, device_id)` 唯一约束。

- 用户身份来自认证上下文，项目访问服从项目权限，设备标识用于设备匹配，禁止充当认证凭据。
- 项目根目录是唯一目录配置，协作资料目录由项目根目录拼接 `docs/` 得出。
- 同一用户在不同设备绑定同一项目，形成不同记录；单个批次固定一个绑定与一台设备，不跨设备混跑。
- 批次保存绑定主键与版本，绑定变更使旧批次失去启动资格，不跟随新目录执行；目录变更前遵守活动执行停止与资源释放规则。

## 3. 任务详情：协作设置

沿用 LINEAR-LITE-124，补充网页控制交互，不重复建立任务编辑实现。

| 配置 | 操作与约束 |
|---|---|
| 允许 Agent 执行 | 授权开关，新任务默认关闭；授权不等于启动 |
| 写入范围 | 录入项目相对路径，以条目展示；错误路径按现有校验契约提示 |
| 前置任务 | 按任务编号和标题搜索同项目任务；沿用叶子任务、自依赖、循环依赖等领域约束 |
| 公共约定 | 沿用公共约定版本引用，不建立文档状态副本 |

保存通过现有协作输入服务，携带输入版本；版本冲突时保留用户输入并提示刷新。父子关系表达需求分组，前置关系表达执行条件，两者分开呈现。

修改活动任务的需求、授权、范围或依赖时，展示影响，提供“保存并停止旧执行”。服务端递增输入版本并触发停止流程，持有范围保留到宿主停止确认；前端禁止用本地状态模拟释放。

任务详情展示输入版本、执行归属、设备、依赖与资源阻塞、检查点、历史成果及停止状态。业务负责人不替代执行实例，任务进度不替代交付证据。

## 4. 项目页面：启动、查看与停止

项目增加“协作执行”入口，任务列表多选后提供“启动协作批次”。启动面板包含任务集合、执行设备及绑定目录、并发数和运行时长上限；尝试次数上限放入高级设置。设备与目录来自已有绑定，页面不要求填写数据库主键、令牌或命令。

服务器检查用户项目权限、设备授权、在线情况、绑定版本和任务输入资格。依赖等待属于执行状态，不等于配置错误；未完成前置任务若不在所选集合中，页面展示等待原因，不擅自扩大授权集合。无效授权、目录或任务输入阻止启动并给出处理入口。

启动请求携带幂等标识，重试返回同一批次。列表与详情展示批次历史、固定任务集合、预算消耗、执行进度、阻塞原因、结果和产物引用；页面通过 HTTP 轮询更新。

| 展示状态 | 含义 |
|---|---|
| 等待领取 | 批次建立，宿主尚未接收 |
| 执行中 | 存在活动任务执行 |
| 等待依赖／资源 | 展示阻塞对象和原因，不将空查询视为完成 |
| 停止中 | 停止意图保存，等待执行退出与停止确认 |
| 已结束 | 展示完成、取消、预算耗尽或失败原因 |
| 待恢复 | 宿主失联或执行归属待恢复，资源保持冻结 |

停止操作按用户项目权限鉴权，不要求用户提供任务领取凭据。未领取批次可取消；已领取批次收到宿主停止确认后才显示结束。批次取消不等于将全部业务任务置为 `canceled`，各任务状态沿用现有停止原因处理规则。

## 5. 宿主连接与后台运行

提供 macOS 宿主安装包，安装流程注册用户级后台服务，用户登录后启动，进程退出后由系统拉起。服务沿用现有宿主执行池，不依赖浏览器标签页维持连接。

首次连接采用现有 OAuth 授权码与 PKCE 机制，增加宿主专用 audience、scope 和设备授权记录。用户在网页登录并确认账号与设备；宿主通过回环回调接收授权结果，凭据保存在 macOS 钥匙串，支持续期与撤销。网站保持网页登录认证，不向宿主传递用户登录令牌。[原生应用 OAuth 规范](https://www.rfc-editor.org/rfc/rfc8252.html)

宿主向服务器发起心跳、领取和回传请求，服务器保存用户、设备、授权与连接事实。宿主实例由授权身份关联，禁止信任请求体中的用户或设备标识来建立权限。

项目设置沿用目录绑定区域，增加安装入口、连接、重新授权、撤销授权和设备状态。设备在线状态取自服务器心跳；浏览器访问本机受阻与宿主离线分开呈现。本机接口保留身份、目录校验及连接引导职责，不承载网页传令牌启动长任务的链路。

撤销授权同时提交停止意图，拒绝新领取、续租和成果写入；保留绑定原批次、执行尝试与宿主归属的停止确认通道，禁止借恢复操作恢复业务写入权。睡眠、关机和网络中断会影响在线状态，页面展示连接状态与恢复入口。

## 6. 服务器批次控制与事实归属

新增持久批次记录，保存批次主键、用户、项目、绑定主键与版本、固定任务集合、并发及预算、运行／停止意图与版本、执行宿主与执行代次、运行租约、起止时间和结束原因。批次授权签发引用这条记录，不另造批次标识。

| 事实 | 来源 |
|---|---|
| 用户、设备与授权、心跳 | 宿主授权与连接记录 |
| 项目目录 | 项目设备绑定记录 |
| 任务需求、授权、计划范围和输入版本 | 现有任务输入字段 |
| 前置关系 | 现有任务依赖表 |
| 批次集合、预算、控制意图与运行归属 | 新增批次记录及集合关联 |
| 领取、租约、检查点、停止与成果 | 现有执行尝试与操作记录 |
| 业务状态 | `tasks.status` |

新增字段沿数据源 → DTO → 前端字段 → 使用点传递；页面状态采用事实读模型，不复制任务完成状态、依赖、检查点或租约到第二套业务记录。

宿主领取批次采用原子归属校验；领取任务、续租、检查点和提交成果检查批次运行意图与执行代次，停止意图与执行请求在协调事务中裁决。过期令牌或旧宿主不能绕过停止控制。

设备心跳、批次运行租约和任务写入租约承担不同职责。心跳中断不能释放写入范围，批次租约失效不能触发另一实例抢跑；执行代次不能替代本机进程停止。物理根目录互斥和停止确认机制保留。

宿主无就绪任务时保持本批次等待，直到依赖满足、收到停止、预算耗尽或需要用户决策。批次开始后固定时限，尝试消耗从该批次执行记录计算；重连、重启和页面刷新不重置预算。恢复前确认旧执行退出，不重复执行失联任务。

数据库结构变更使用 DBX，增量脚本归档到 `schema.sql`；不建立兼容层或旧字段双读双写。

## 7. 开发任务组织

创建网页控制总任务，归入既有总任务 LINEAR-LITE-113；新增子任务按“认证与服务器控制 → 宿主运行 → 网页接入 → 网页流程交付”推进。

复用 LINEAR-LITE-124 承担任务配置与痕迹展示，补充本方案交互要求；复用 LINEAR-LITE-125 承担既有协议集成核验，不另建同范围实现。新增网页流程交付任务覆盖网页与后台宿主组合行为，承接原协议核验结果。

开发依赖以各任务卡“依赖关系”中的编号与本文件任务表为准；父子关系用于归档。当前项目管理插件的创建、更新任务接口不提供前置依赖字段，本轮不伪称写入结构化执行依赖，也不替用户开启任务执行授权。

## 8. 范围边界

本轮产出为方案文档及任务卡，不开发、不执行数据库脚本、不部署、不运行模型批次、不启用定时任务。后续运行沿用用户指定环境、任务与范围，定时任务启用按用户指令执行。

实施范围不包含跨设备混合批次、代码同步、Codex 侧边栏持久会话、Pi 执行模型改造、MQ 或事件总线。
