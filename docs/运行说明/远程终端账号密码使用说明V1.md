# 远程终端账号密码使用说明 V1

## 团队身份

项目创建者在项目设置的远程终端中，为服务器添加身份，选择“账号密码”，填写登录账号和密码，再授权项目成员。编辑身份时，密码留空表示保留现有密码。改用证书认证会清除保存的密码。

服务端加密保存密码。获授权成员的 MCP 为建立 SSH 连接取得密码。撤销授权或关闭 MCP 会话不能使已经取得的密码失效；需要收回访问权限时，修改服务器密码。密码身份的 PTY 限制由 MCP 执行，取得密码的成员可以通过其他 SSH 客户端绕过该限制。

成员使用支持密码身份的 remote-terminal-mcp 版本，按团队版 Codex 接入说明更新客户端并重启 Codex。服务器须启用 SSH 密码认证；主机公钥需要事先核对。

## 本机身份

本机模式的身份配置使用 `password_file`，值为仓库外密码文件的绝对路径，并填写 `profile_id`、`login_user` 和 `max_ttl_seconds`。密码文件使用 UTF-8，权限设置为 `0400` 或 `0600`；文件内容原样用于认证，换行符属于密码的一部分。配置和 MCP 工具参数不填写密码。
