# LINEAR-LITE-133 宿主安装与连接 V2

本版对应 LINEAR-LITE-134、135 的后台批次控制和网页连接实现，V1 保留为历史交付记录。

## 安装与连接

1. 在项目设置的“项目目录绑定”点击“下载宿主”，下载当前服务版本的安装包。
2. 打开 DMG 中的“Linear Lite 协作宿主安装”，输入 Linear Lite 站点的 HTTPS 地址，选择“安装”。
3. 选择“连接”，在系统浏览器确认账号与设备授权。
4. 返回项目设置，检查本机浏览器连接、设备授权与服务器心跳，绑定项目根目录。
5. 打开用户“应用程序”中的“Linear Lite 协作宿主”，使用连接、状态、退出授权或卸载入口。

交付文件：`docs/交付产物/Linear-Lite协作宿主-macOS-arm64-V2.dmg`。适用 Apple Silicon、macOS 11 及以上，内含 Node.js 22.23.4 与许可证，不依赖 Homebrew 或另装 Node.js。安装应用使用 ad-hoc 签名，未经 Apple 公证；系统阻止打开时，在系统设置查看应用安全提示。安装器保留系统隔离标记。

网页使用当前账号认证下载安装文件，本机连接不接收网页登录令牌或 Cookie。网页登录后，OAuth 授权码与 PKCE 由宿主处理，访问令牌与刷新令牌保存在 macOS 钥匙串。

## 后台批次与停止恢复

用户登录后，LaunchAgent 启动宿主；进程退出后，系统按注册规则启动服务。宿主向服务器发送心跳并轮询授权设备的待领取批次。关闭网页不影响后台批次；安装或连接不会创建任务授权或批次。

批次固定任务集合、目录绑定、并发、截止时间和尝试预算。依赖与资源等待属于本批次，不因查询为空而结束。网页刷新、网络恢复和宿主重启不重置服务端预算或消耗。电脑睡眠、关机或断网影响心跳和连接，网页按服务器事实展示在线状态。

停止意图阻止新任务启动。宿主封存写入能力，结束托管执行进程组，提交任务停止确认并结束原批次；服务器确认前，范围、目录根锁和恢复凭据保留。断网后的收口依赖执行池交出的停止证明；证明缺失、进程存活或结果不明时保留冻结。宿主重启使用原批次凭据恢复旧代次，不续跑旧执行。

进程组核对覆盖宿主管理的 app-server 及登记进程组；主动创建新会话的只读后代不属于该物理退出证明，宿主写入能力封存承担业务写入边界。

网页“撤销授权”针对所选服务器授权记录，服务器拒绝该授权的新领取、续租和成果写入，并提交关联批次的停止意图；撤销成功不代表进程退出或范围释放。宿主心跳识别失效授权，连接操作完成新授权并替换钥匙串记录。应用“退出授权”撤销本机授权并清理对应钥匙串项。

## 状态与目录

一个用户、一个项目、一台设备对应一条目录绑定，协作资料目录从项目根目录拼接 `docs/` 得到。其他设备绑定在网页中以只读方式展示。浏览器回环连接受阻与服务器宿主离线分别显示，连接错误不能作为任务停止证明。

目录变更被活动执行阻止时，网页提供相关批次的停止入口；停止意图保存后，目录变更仍受服务器冻结门禁约束。没有持久批次归属或缺少原恢复资料的执行不能通过网页解除冻结。

状态目录沿用 `~/Library/Application Support/Linear-Lite/CodexHost`，配置保存站点来源，设备身份、根锁和恢复关联保留在本机。安装器管理 `com.linearlite.codex-host` 用户服务；其他进程占用 9781 端口时显示进程号并提供活动监视器入口。安装、替换和卸载遇到根锁或待恢复执行时阻止操作。

## 发布与构建

服务器须部署 130、131、132 的授权与持久批次能力及 135 的安装下载接口。本版安装包随服务器打包到非静态资源目录 `host-distribution`，缺包报错，不回退到 V1。

开发构建命令：

```sh
node codex-host/install/build.mjs --output docs/交付产物/Linear-Lite协作宿主-macOS-arm64-V2.dmg
```

构建在 Apple Silicon macOS 和 Node.js 22 及以上环境执行，检查运行时架构、系统动态库依赖、签名与许可证；输出路径存在时拒绝覆盖。
