# LINEAR-LITE-124 任务协作设置 V1

任务详情中的“协作设置”使用现有任务输入与执行记录。允许 Agent 执行、项目相对写入范围、前置任务及公共约定文档版本通过 `/api/collaboration/inputs/get` 与 `/api/collaboration/inputs/replace` 读取和保存。保存请求携带读取的 `inputRevision`；开启授权不启动批次。空写入范围表示无写权限，路径中的空格按原值提交。

前置任务按同项目任务编号或标题搜索，父子关系沿用任务详情原有展示。公共约定从项目文档中选择并记录版本；引用不随文档版本变化自动更新。叶子任务、依赖环、跨项目依赖和写入范围由领域服务校验，界面展示服务端原因。

执行事实使用 `/api/collaboration/tasks/state`，请求携带当前任务键和输入版本。服务端在协调事务内返回配置状态、绑定维度输入与资源状态、历史执行、设备标识、检查点、成果及停止事实，不返回任务领取凭据或其他成员的本机路径。服务端时间用于识别过期租约；过期不表示停止确认。

提交前重新读取执行事实。存在活动或冻结执行时，保存动作要求确认并说明停止影响；服务端负责提交停止请求与失效处理，范围释放以宿主停止确认为准。冲突或读取失败保留当前表单输入；读取服务器版本前，界面要求确认放弃尚未保存的修改。保存成功后若读取状态失败，界面区分保存成功与刷新失败。

保存后的任务状态使用同一输入版本的服务端状态；项目任务列表用于读取下游失效事实。任务缓存按 `inputRevision` 应用较新协作事实，旧普通编辑响应不得将过期状态覆盖新版本；正文和用户尚未提交的状态变更保留在普通保存队列。输入、事实和项目列表的异步响应受用户、项目和任务上下文约束，切换上下文时不写入旧响应。

此说明覆盖任务设置接入。安装、项目目录、批次启动与停止使用各自的网页和宿主操作；真实模型运行与网页端到端验收结果以对应交付记录为准。
