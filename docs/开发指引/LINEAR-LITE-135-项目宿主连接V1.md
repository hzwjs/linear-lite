# LINEAR-LITE-135 项目宿主连接 V1

项目设置的“项目目录绑定”提供宿主安装包下载、本机连接与重新授权、账号设备授权状态和撤销入口。

安装包通过带网页登录认证的 `GET /api/collaboration/host-installer` 下载，不在下载地址中附加凭据。安装包对应 macOS Apple Silicon；安装与系统限制参见 LINEAR-LITE-133 宿主安装说明。

本机宿主的 `/status`、`/connect` 只接收请求用途对应的参数；网页不发送登录令牌或 Cookie。授权使用浏览器账号确认，宿主负责凭据保存和刷新。本机连接状态取自回环接口，账号设备的授权、在线状态和心跳取自服务器，回环不可达不改变服务器返回的设备状态。网页撤销指定授权记录；宿主心跳识别撤销状态，重授权替换旧凭据。

项目目录沿用 `(用户、项目、设备)` 绑定；其他设备绑定以只读方式展示，本机提交先调用宿主目录校验。协作资料目录从项目根目录推导，不新增目录配置。项目或用户切换后重新读取绑定、设备和连接状态；后台状态刷新不覆盖编辑中的目录。

目录保存或删除被服务器冻结规则阻止时，页面读取当前账号的批次分页，按所选绑定展示未结束批次。用户可提交停止意图；页面显示停止处理中，目录变更继续接受服务器冻结检查。没有持久批次归属的旧执行显示服务器错误，需由原宿主恢复或确认，不通过网页推断执行退出。
