# LINEAR-LITE-139：批次授权与预算契约 V2

## 服务端契约

批次的任务集合提供任务执行授权。领取和执行仍校验项目成员权限、用户与设备绑定、绑定版本、批次代次、租约和停止状态；同一任务已有未确认的执行时不得再领取，其他任务不受路径重叠限制。批次任务、执行记录或依赖关系任一存在，即认定任务参与协作；排队批次中的任务也受完成门禁和输入变更失效保护，普通任务不受协作完成门禁约束。

启动请求字段为 `projectId`、`operationId`、`bindingId`、`bindingRevision`、`taskIds`、`maxDurationMs`。请求包含未定义字段时拒绝，包括旧的 `maxSlots` 和 `maxAttempts`。服务端将槽位预算设为 1，将执行次数预算设为 `max(5, taskIds.size())`，任务集合上限为 200，超限拒绝。时长为正整数毫秒，上限为 `Long.MAX_VALUE / 1_000_000`；超出范围拒绝。预算在创建时写入批次，幂等重放读取原批次，不按新默认值重算。

交付可以没有文件变更、证据引用和产物引用；存在产物引用时需要项目检查点。实际产物路径仍须满足项目相对路径格式，路径格式校验不构成任务写入范围或路径互斥。

## 删除的契约

- 任务字段 `write_scopes`、`agent_execution_enabled`、`public_context_refs` 和执行记录字段 `held_write_scopes`，以及对应 DTO 与查询字段。
- REST 任务输入全量替换和宿主范围扩张接口；MCP 工具 `replace_task_collaboration_inputs`、`expand_collaboration_write_scopes`。
- 范围占用、重叠判断、范围扩张和交付路径包含检查。任务输入读取保留输入版本与依赖事实。

数据库删除字段脚本为 `docs/运行说明/部署脚本/20261110-LINEAR-LITE-139-删除旧协作配置.sql`，并归档到 `schema.sql`。脚本中的 `SET`、`PREPARE`、`EXECUTE` 和 `DEALLOCATE PREPARE` 依赖同一个数据库会话；执行时通过 DBX 使用同一个 `session_id` 并显式选定目标库。脚本未执行。服务端、数据库和调用端切换需要统一安排；旧客户端字段和接口不受支持。

## 后续任务边界

消费事实、自动依赖和发现成果流程由后续任务完成；网页和本机宿主仍须适配此契约。服务端单元测试不证明网页、宿主和模型端到端联通。本任务未部署、未操作数据库、未运行模型和定时任务。
