# LINEAR-LITE-136 网页批次控制 V1

## 项目入口与启动

项目侧栏提供“协作执行”入口。任务列表支持多选任务后进入批次启动区，页面展示所选任务、授权设备和项目目录，并提供并发、运行时长和尝试次数上限。设备及目录来自当前账号的授权和项目设备绑定；未授权或离线设备不可选择，可从页面进入项目设置处理。

任务标识和标题来自任务列表，启动请求的任务主键来自同一任务 DTO 的 `numericId`。用户无需填写数据库标识。任务协作授权、范围、依赖和公共约定由任务协作设置维护；批次页读取现有字段，不保存第二套配置。

启动前，网页将完整 `StartRequest` 与 `operationId` 保存到浏览器标签页的 sessionStorage，按账号和项目分开；数据不包含令牌。保存失败时不发送启动请求。启动结果不明时，原请求留在存储中，页面提供显式重试，重试使用同一请求与标识；刷新、页面加载或关闭不会自动启动或取消批次。

用户确认放弃重试会清除本机待重试记录；该操作不取消可能已创建的批次，用户可在历史中确认。启动成功后页面进入服务端返回的批次详情。

## 批次与任务状态

批次历史与详情使用服务端 HTTP 接口，按需加载历史页并轮询当前事实。页面展示设备、固定预算、尝试消耗、开始时间、截止时间和结束原因，以及等待领取、等待执行、运行、依赖或资源等待、停止、待恢复与结束状态。目录绑定版本与批次版本一致时展示目录，版本变化时展示绑定变化，不把新目录视为原批次目录。结束状态由服务端生命周期与停止确认决定；页面不以浏览器关闭或超时推断任务完成。

详情展示所选任务的依赖对象、等待原因、范围和输入版本，执行尝试展示检查点发现、阻塞原因、完成条件、证据引用、修改路径与产物引用；本机文件引用按文本呈现，不伪造下载地址。依赖任务若无法访问，页面展示任务不可用，不擅自扩大批次任务范围。

停止操作提交服务器停止意图并读取服务端状态；执行退出及停止确认前的范围冻结由服务端和宿主维持。已结束批次与运行记录可从历史再次打开。

## 接口与数据归属

`src/services/api/collaborationBatch.ts` 维护批次启动、停止、列表与详情接口，以及对应服务端 DTO 的前端类型。项目设置的冻结处理和批次页共用该接口；授权与设备心跳沿用 `collaborationHostApi`，项目目录沿用 `projectDeviceBindingApi`。

列表、任务状态、检查点、成果和结束原因来自服务端数据；网页不创建执行事实副本。批次状态与执行尝试状态分别使用共享映射和状态标签，未知状态保留原始状态文字。
