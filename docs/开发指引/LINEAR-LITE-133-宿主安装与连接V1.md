# LINEAR-LITE-133 宿主安装与连接 V1

## 适用范围

交付文件为 `docs/交付产物/Linear-Lite协作宿主-macOS-arm64-V1.dmg`，适用于 macOS 11 及以上的 Apple Silicon 设备。安装包包含 Node.js 22 运行时及其许可证，不需要安装 Homebrew 或 Node.js。

安装应用使用临时签名，未经过 Apple 公证。若系统阻止打开，请查看系统设置中的应用安全提示。安装器不会移除系统隔离标记。

## 安装与连接

1. 打开 DMG，打开“Linear Lite 协作宿主安装”，输入 Linear Lite 站点的 HTTPS 地址。
2. 选择“安装”。安装器将应用放入当前用户的“应用程序”，注册当前用户的 LaunchAgent。
3. 选择“连接”，在系统浏览器中登录并确认设备授权。登录页由站点提供，宿主不接收网页登录令牌。
4. 打开 `~/Applications/Linear Lite 协作宿主.app`，可选择“连接”“状态”“退出授权”或“卸载”。状态显示设备和连接信息，不显示凭据。
5. 回到同一站点的项目设置，完成本机项目目录绑定。

站点须提供 LINEAR-LITE-130 和 LINEAR-LITE-132 对应的宿主授权接口。LINEAR-LITE-133 提供安装、身份、连接与心跳；批次领取和执行属于 LINEAR-LITE-134 的范围。

## 运行与状态

用户登录后，LaunchAgent 启动宿主；进程退出后由 LaunchAgent 拉起。关闭浏览器不影响宿主。电脑休眠、关机或网络不可用时，宿主无法保持在线；恢复网络后，宿主继续发送心跳。授权失效后，状态显示需要授权，选择“连接”可重新授权。

宿主状态目录沿用 `~/Library/Application Support/Linear-Lite/CodexHost`。设备身份、项目根目录锁和待恢复执行使用该目录；授权令牌保存在当前用户的 macOS 钥匙串，刷新令牌时更新同一凭据项。配置文件保存站点地址，不保存令牌。宿主每 30 秒发送心跳，本机接口校验请求的 Host 和站点 Origin。

安装器仅管理标签为 `com.linearlite.codex-host` 的宿主服务。9781 端口被其他进程占用时，安装器显示进程号并提供“打开活动监视器”入口；退出原协作宿主后重试。安装器不会向未受管理的进程发送信号。

存在根目录锁或待恢复执行时，安装、重装和卸载会停止，保留恢复数据。受管服务升级失败时，安装器尝试恢复原应用、配置和服务。卸载移除受管应用、LaunchAgent、站点配置及授权凭据，保留设备身份和恢复数据；撤销授权或删除钥匙串凭据未能确认时会显示提示。

## 构建

在 Apple Silicon macOS 和 Node.js 22 或以上环境执行：

```sh
node codex-host/install/build.mjs
```

构建脚本校验 Node 架构、签名、许可证和动态库依赖；运行时仅允许依赖 macOS 系统动态库。可用 `--node`、`--license`、`--output` 指定运行时、许可证和产物位置；已存在的产物不会被覆盖。
