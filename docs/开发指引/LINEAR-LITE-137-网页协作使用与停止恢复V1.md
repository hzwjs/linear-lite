# LINEAR-LITE-137 网页协作使用与停止恢复 V1

## 连接设备与项目

1. 在项目设置打开“项目目录绑定”，下载本机宿主安装包。
2. 打开安装应用，填写站点 HTTPS 地址，完成安装及浏览器账号设备授权。
3. 在项目设置查看浏览器连接、设备授权和服务器心跳，绑定本机项目根目录。

一个用户、一个项目、一台设备对应一条绑定；协作资料目录从项目根目录拼接 `docs/` 得到。其他设备的绑定供查看，不允许在当前电脑修改其路径。浏览器回环连接受阻与服务器宿主离线是不同事实。

安装环境、签名与卸载说明见 [宿主安装与连接 V2](LINEAR-LITE-133-宿主安装与连接V2.md)。服务器须部署对应版本的授权、持久批次和网页接口；本文不代表部署或真实运行验收结果。

## 配置任务

1. 打开任务详情中的“协作设置”。
2. 设置“允许 Agent 执行”，添加项目相对路径作为写入范围。
3. 按任务编号或标题搜索前置任务，选择公共约定及其文档版本。
4. 保存配置；存在活动或冻结执行时，确认“保存并停止旧执行”。

授权开启不创建批次。空写入范围表示不授予写权限，适用于只读任务；非法路径、依赖环、自依赖及跨项目依赖由服务器拒绝。父子关系表达需求分组，前置关系表达执行条件，两者不互相替代。

协作输入变更会递增输入版本，使当前及受影响下游的旧成果失去就绪依据；已完成任务可回到待办。活动执行等待宿主停止确认，持有范围保持冻结。版本冲突保留编辑内容，用户可选择加载服务器版本。

输入就绪、设备在线、执行授权和本机成果可用性分别展示。检查点、历史成果与当前有效成果按执行尝试及输入版本区分，任务进度不能替代交付证据。

## 启动与查看批次

1. 在项目任务列表勾选任务，点击“启动协作批次”。
2. 核对任务集合、授权设备与目录，设置并发数和运行时长；尝试次数上限位于高级设置。
3. 确认启动后，在“协作执行”查看批次历史与详情。

任务编号和标题用于选择，设备与目录来自现有授权及绑定。页面不要求填写令牌、数据库编号或命令，也不替用户添加未选择的前置任务。缺少前置成果时，所选下游在原批次等待。

启动请求在发出前保存到当前标签页的会话存储，内容包含幂等标识与原参数，不包含凭据。结果待确认时，使用“重试上次启动”；刷新后的重试使用原请求。放弃重试清除本机记录，不取消可能创建的批次，操作前须查看历史。

离开或关闭页面不发送取消请求。新标签页或会话存储清除后，通过批次历史核对结果，避免把结果不明的启动当作未创建。

| 状态 | 操作含义 |
|---|---|
| 等待领取 | 批次保存，等待授权宿主接受 |
| 等待执行／执行中 | 宿主拥有运行归属，任务等待槽位或正在执行 |
| 等待依赖／资源 | 查看前置任务、成果或范围阻塞，不代表完成 |
| 停止中 | 停止意图保存，等待进程退出与停止确认 |
| 待恢复 | 执行归属、租约或停止事实待核实，资源保持冻结 |
| 已结束 | 服务器记录批次结束，可查看结束原因和成果 |

批次详情展示固定预算、尝试消耗、起止事实、检查点及产物引用。文件路径按引用文本展示，页面不伪造本机文件下载地址。绑定版本变化时，页面显示绑定变化，不把新目录当作历史执行目录。

## 停止与恢复

1. 在批次详情点击“停止批次”，确认操作。
2. 查看服务器状态；停止响应表示意图保存，不表示执行退出。
3. 宿主封存写入能力、结束托管进程组、提交各尝试的停止确认后，服务器记录批次结束。
4. 目录变更被阻止时，可在项目设置提交相关批次的停止意图，等待停止确认后重试目录操作。

断网、睡眠或宿主退出不能作为范围释放依据。宿主使用原批次恢复凭据，核对根锁及执行停止事实后收口旧代次；同进程断网恢复需要执行池的停止交接证明。缺少凭据、归属变化、进程存活或创建结果不明时保留冻结，网页没有强制解除冻结入口。

撤销设备授权阻止该授权的新领取、续租和成果提交，并触发关联批次停止；停止恢复保留归属受限的专用通道。授权撤销成功不等于任务取消、进程退出或目录锁释放。

进程退出证明覆盖托管 app-server 与登记进程组，不证明主动脱离进程组的任意只读后代退出；业务写入受宿主封存门禁约束。

## 本轮交付边界

用户指定本轮为开发和协议核验。真实网页安装授权、服务器部署、真实模型依赖推进及停止恢复运行保留待验收，模拟结果不能替代真实结果。定时任务保持关闭。
