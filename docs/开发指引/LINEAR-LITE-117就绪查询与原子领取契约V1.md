# LINEAR-LITE-117 就绪查询与原子领取契约 V1

服务提供观察、领取和写入范围扩张；宿主、REST/MCP 与交付命令属于后续任务。

`CollaborationBatchRequest` 携带批次凭据、绑定、设备与项目根目录；`CollaborationAttemptCommand` 携带执行尝试、领取凭据、输入版本、宿主/执行实例与请求标识。请求对象的字符串表示隐藏凭据。

## 观察

`TaskCollaborationClaimService.observe` 以批次授权的任务范围返回任务现状、描述、输入版本、路径、前置成果快照、执行历史与阻塞原因。聚合状态包括 `READY`、`DEPENDENCY_WAIT`、`RESOURCE_WAIT`、`ACTIVE`、`COMPLETE`、`BLOCKED` 和 `EMPTY`；禁止根据空结果推断完成。

前置结果快照包含任务、执行尝试、输入版本与成果证据。宿主声明可用成果时使用执行尝试 ID 和输入版本；服务不检查宿主文件系统。任务完成以同绑定、当前输入版本、停止确认与成功成果为依据。

## 领取

`claim` 在 `READ_COMMITTED` 事务内校验批次、项目锁、任务状态、输入版本、依赖与范围；创建运行尝试和范围快照并调用任务状态服务。冲突返回可解释原因，事务提交后释放数据库锁。活动与等待停止确认的执行按项目级任务互斥；范围按绑定级互斥。租约初始有效期为五分钟。

领取标识由服务端按固定用途和批次、绑定、任务、宿主、执行实例及操作标识派生，尝试记录只保存摘要。请求回执保存无凭据的请求和响应事实；相同操作标识重放相同结果，篡改请求遭拒。返回领取标识用于后续业务认证；日志、检查点和文档禁止保存该标识。

## 范围扩张

路径是规范化项目相对路径；去除尾部 `/` 后，路径相等或存在斜线分隔的父子关系均视为冲突，`src` 与 `src2` 不冲突。物理路径与符号链接由宿主校验。`expand` 在归属校验、操作回执与执行资格校验后检查冲突；冲突时保存停止意图及原持有范围，停止确认前范围保持占用。停止确认后的范围快照用于历史追溯，不参与冲突判断。

## 事务边界

批次认证建立项目协调锁。业务操作在同一 `READ_COMMITTED` 事务中完成；`TaskExecutionAccessService` 将归属与当前写资格拆分，允许幂等回执在归属校验后重放，阻止旧业务请求恢复写权。发现租约过期或当前输入失效时，服务记录停止意图并返回拒绝，调用方需要提交事务以保留停止事实。
