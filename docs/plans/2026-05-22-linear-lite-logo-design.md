# Linear Lite Logo 设计记录

**目标：** 为 Linear Lite 生成一套克制、可直接用于产品界面的品牌标记。

**设计判断：**

- 采用几何 `L` 标记，避免直接复刻 Linear 的紫色品牌语言。
- 图形由外框、折线和节点组成，表达任务路径、轻量推进和工作流收敛。
- 色彩沿用项目当前浅色工作台基调：白色表面、slate 灰蓝主色、低存在感边框。
- 资产优先使用 SVG，确保 favicon、侧边栏、登录页和文档场景都能清晰缩放。

**交付范围：**

- `public/logo-mark.svg`：应用 favicon 和小尺寸图标。
- `public/logo-lockup.svg`：完整品牌组合。
- `docs/logo/linear-lite-logo.svg`：文档侧完整 logo。
- `docs/logo/linear-lite-logo-dark.svg`：深色背景版本。
- `docs/logo/preview.html`：本地预览和规格说明。
