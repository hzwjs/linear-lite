# LINEAR-LITE-130 与 131 交付记录 V1

日期：2026-11-10。基线：`10ff318`，交付对象为该提交基础上的本轮工作区改动。

## 1. 交付结论

LINEAR-LITE-130、LINEAR-LITE-131 的服务端开发与本轮验收完成，联合回归为 37 组、255 项，失败、错误和跳过数量为 0。对应架构决策核对没有阻断项。

本结论覆盖服务端授权、持久批次控制和相关生命周期，不代表网页、宿主后台服务或真实模型全流程完成。LINEAR-LITE-132 至 137 承担后续执行门禁、宿主和网页接入；LINEAR-LITE-124、125 保持原任务范围。

## 2. LINEAR-LITE-130

- 宿主采用专用 scope 与 audience；授权确认页展示账号及设备，SAS 校验授权码与 S256 PKCE 后建立用户设备授权记录。
- 每次新 OAuth authorization 建立新 grant，旧 grant 保留并撤销；刷新沿原授权并校验撤销事实。
- 提供本人授权历史、撤销和宿主心跳接口，在线状态按服务端 90 秒心跳时限计算；UTC 时间以 Instant 输出。
- 网页、MCP、远程终端与宿主凭据按用途鉴权；恢复身份输出 STOP_ONLY，不建立普通用户写入身份，不释放执行资源。
- 补齐 SAS 公共客户端刷新与撤销的认证接入；client_id 用于定位客户端，签发取决于令牌、客户端、资源、有效期、轮换与授权归属校验。
- JWT 失败归一为认证错误，区分过期与显式授权撤销；恢复路径放行过期声明，但不放行无效签名或其他无效 JWT。

接口说明：`docs/开发指引/LINEAR-LITE-130-宿主授权接口V1.md`。

客户端回环回调的预期 state 校验归 LINEAR-LITE-133。刷新重放撤销 refresh family，不等同于用户显式撤销设备 grant；有效 access token 的行为沿现有 TTL 契约，显式授权撤销会阻止普通宿主请求。

## 3. LINEAR-LITE-131

- 新增 `collaboration_batches` 与 `collaboration_batch_tasks`，固定用户、项目、绑定版本、授权记录、任务集合和运行预算。
- 提供网页用户启动、停止、列表和详情接口；复用既有操作回执机制，幂等重试返回原结果，异载荷或异操作复用同 key 返回冲突。
- 启动校验本人绑定、项目权限、设备授权与在线状态、任务授权及输入配置；空写入范围作为只读计划，依赖等待不误判为配置无效。
- 批次接受与取消采用事务锁及条件更新。未接受取消可结束，已接受停止保持等待确认，重试不重置起止时限或执行代次。
- 任务读模型读取现有任务、依赖与执行尝试，分开表达输入就绪、活动冻结、范围占用和宿主成果检查；`inputsReady` 不等于可领取。
- 已接受但尚无任务尝试的批次纳入目录绑定冻结和项目删除等待；项目停止沿独立提交事务，清理前复查并删除批次关联与批次记录。

接口说明：`docs/开发指引/LINEAR-LITE-131-协作批次控制接口V1.md`。

131 的接受方法是内部原语，不开放宿主执行 HTTP/MCP 入口，不签发新持久批次执行令牌；执行领域门禁由 LINEAR-LITE-132 接入。原有 issue 链路不承载新控制批次的持久状态。
