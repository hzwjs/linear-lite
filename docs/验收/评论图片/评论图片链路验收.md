# 评论图片链路验收

## 问题与修复

评论 Markdown 中保存的图片地址指向任务附件下载接口。浏览器的 `<img>` 请求不会附带 Axios 使用的 Bearer 请求头；下载接口也按附件下载响应处理，因此图片没有形成可供评论展示的授权读取链路。截图能确认图片像素未显示，但本次没有浏览器网络记录，未将某个 HTTP 状态码当作实测结论。

MCP 评论现支持 `mcp-image:<ref>` 图片引用、单任务附件 `attachmentId` 引用、图片绑定读回及 `list_task_comments`。评论图片通过 `/api/document-assets/task-comments/{commentId}/{imageId}` 读取，沿用 `/api/document-assets` 的登录 Cookie，并在每次读取时校验任务成员权限。

```json
{
  "taskKey": "TEST-1",
  "operationId": "comment-image-e2e-001",
  "body": "验收图片：![列表](mcp-image:list)",
  "images": [
    {
      "ref": "list",
      "fileName": "list.png",
      "contentType": "image/png",
      "dataBase64": "<图片 Base64>"
    }
  ]
}
```

`operationId` 重放会返回原评论；同一 `operationId` 携带不同正文或图片会报冲突。每条评论最多 8 张，单图不超过 6 MiB，总量不超过 12 MiB。只接受 PNG、JPEG、GIF、WebP。引用的附件必须属于同一任务；绑定期间锁定附件记录，已被评论引用的附件不能删除。
