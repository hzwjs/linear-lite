## 实现与依据

任务列表多选接入批次启动面板，确认任务、设备、绑定目录和预算；侧栏提供协作执行入口，历史与详情通过 HTTP 读取和轮询服务器事实。启动前持久保存按账号和项目隔离的原请求与幂等标识，刷新显式重试；存储失败阻止发起，迟到响应不能清除另一请求。关闭或取消页面不提交停止意图，放弃重试不等于取消服务器批次。

批次详情展示生命周期、依赖与资源等待、停止、恢复、预算消耗和结束原因，复用执行尝试、检查点与成果引用。目录展示受绑定版本约束；文件引用按文本展示，不伪造下载地址。项目设置与批次页使用同一批次 API 与类型。

任务详情的授权、写入范围、前置任务与公共约定版本沿用现有输入服务；空写入范围适用于不授写权限的任务。新增 `/api/collaboration/tasks/state` 提供版本耦合的只读事实，任务、项目和账号权限由服务端核对；历史设备信息不包含其他用户目录或领取凭据。读取不调用具有停止副作用的观察入口。

保存后的输入与同版本业务状态形成一个协作影响字段组，更新现有列表、保存队列确认基线、缓存和项目快照；迟到旧响应不能恢复旧完成状态，正文和标题草稿保留。宿主同版本交付通过请求前后观测标记核对后同步，普通编辑期间的旧观测被丢弃。没有新增业务状态表、缓存体系或通用自动重试。

协议核对修正任务租约的时间比较：任务租约按北京时间保存，批次时间按 UTC 保存，读模型将任务租约转换为 `Instant` 比较。租约到期表示待恢复，不构成进程退出或停止确认。
