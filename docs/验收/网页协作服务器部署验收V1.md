## 网页测试步骤

1. 使用 HTTPS 域名登录，刷新页面，进入 Linear-Lite 项目的项目设置 → 项目目录绑定。
2. 点击“下载宿主”，打开 V2 安装应用，填写 `https://linearlite.eobua.cn`，完成安装及浏览器设备授权；返回网页查看设备授权、心跳和目录绑定。安装器报告 9781 端口占用时，使用其活动监视器入口处理旧宿主。安装签名、系统安全提示与卸载说明见 [宿主安装与连接 V2](../开发指引/LINEAR-LITE-133-宿主安装与连接V2.md)。
3. 在验收任务详情打开“协作设置”，填写允许执行、项目相对写入范围、前置任务和公共约定，然后保存。授权开启不创建批次。
4. 在项目任务列表勾选验收任务，打开“启动协作批次”，核对任务、设备、目录、并发和时长，然后取消面板。本轮不点击确认启动，确认启动会创建可被宿主领取的模型批次。
5. 打开左侧“协作执行”查看批次历史入口。本次没有创建新批次，空列表属于预期结果；停止和运行状态需要下一轮真实批次验收。

## 回滚

应用回滚使用原启动脚本停止服务，把 `previous.jar` 复制到临时文件后替换活动 JAR，再使用原启动脚本启动并核对 HTTP 检查。保留 `.env`、`config/` 和文档协作服务。旧 JAR 不依赖新增三表；回滚应用时保留新增表和可能出现的新业务事实。

数据库备份用于按事故范围恢复；存在部署后写入时，不覆盖原表。需要数据库恢复时，通过 DBX 执行并记录恢复范围；不通过远程 shell 连接数据库。
