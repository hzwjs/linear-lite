# Markdown 图片与折叠导入验收记录 V3

日期：2026-10-04。V1、V2 记录保留。

## 处理结果

- Markdown 图片引用转换为 `documentImage`，正文保存 `imageAssetId` 和说明文字，资源信息通过现有图片清单解析。
- 导入前列出图片相对路径。缺失图片时等待补选，不创建文档；提供图片文件、图片目录和逐项选择入口。Markdown 与配套图片支持组合拖拽。
- `<details>/<summary>` 转换为编辑器原生 `toggleListItem`，标题取 summary，内容成为子块。折叠区域初始收起，Mermaid 子块显示源码，区域外显示图片。
- 导入完成首版正文、附件、历史记录和索引事件后返回结果，沿用文档事务工厂与图片上传服务。没有新增数据表、字段或兼容字段。
- 图片校验使用解码结果确定类型，不采用客户端声明的 MIME 作为图片判据。不可解码的图片在创建文档之前拒绝。

文件要求：UTF-8 `.md`，上限 5 MiB；图片支持 PNG、JPEG、GIF，最多 8 个相对路径，单张上限 6 MiB，总大小上限 12 MiB，单张像素总量上限 6400 万。远程图片 URL、Markdown 表格或链接内图片不属于本次支持范围。其他 HTML 块保留为源码。

MCP 图片资源契约保留，文件导入使用独立入口。资源路径在转换阶段绑定图片，持久化正文不保存本地文件路径或图片 URL。
