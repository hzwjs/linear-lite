# Markdown 拖拽导入验收记录 V1

日期：2026-10-04

## 交付行为

- 文档目录树接收本地 `.md` 文件。拖到文档行时创建子文档，拖到空白区域时创建根文档。
- 文档侧栏的 MD 按钮提供文件选择入口，支持多文件导入。
- 标题取文件名，移除扩展名；正文转换为现有 BlockNote 格式，可进入编辑器修改。
- 导入结果按文件展示。失败项保留原文件与目标目录，重试不重建成功项；目录刷新失败提供刷新入口。
- 文件上限为 5 MiB，编码为 UTF-8。图片引用和 HTML 块返回错误，避免正文缺失；图片可在编辑器内上传，HTML 可使用现有 HTML 文档入口。

## 数据路径

`multipart .md 文件 → MarkdownToBlockNoteConverter.convertFile → ProjectDocumentCommandService.create → project_documents.content → ProjectDocumentResponse.content → 文档编辑器`

创建沿用项目成员权限、父文档归属校验、首版历史记录和索引事件。Markdown 转换完成后进入创建事务，转换失败不创建空文档。未新增数据库字段、兼容字段或数据库脚本。
