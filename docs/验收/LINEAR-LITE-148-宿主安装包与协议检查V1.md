## 安装、升级与卸载

1. 实际切换前，按切换准备流程停止接受旧批次，确认活动与待恢复执行收口，保留旧批次记录和备份。新协议使用新批次凭据，旧批次恢复须在旧服务切换前处理。
2. 获得运行指令后，从项目设置的「下载宿主」下载，或打开本次交付镜像。运行安装应用，输入当前 Linear Lite 站点的 HTTPS 地址。
3. 升级沿用现有设备标识、站点配置位置和钥匙串。已有授权时可选择「稍后」，在安装应用的「状态」或网页设备设置确认原授权和目录绑定。新设备按「连接」完成浏览器授权。
4. 安装器检查运行、尝试和进程组记录，在关闭自有后台服务和释放 9781 后复查。存在待恢复执行时保留现场。外部进程占用 9781 时提示进程归属。旧根记录只用于识别旧安装的待收口现场。
5. 卸载停止自有后台服务并移除安装应用和服务注册，保留设备标识、站点配置、账号授权、钥匙串与服务器目录绑定。「退出授权」用于撤销授权。后台服务保活与批次定时触发各用独立入口，定时触发默认关闭。
