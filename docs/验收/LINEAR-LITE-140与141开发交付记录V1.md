## 交付内容

- **140**：复用项目文档服务发现和读取内容，正文与版本取同一快照；读取授权事务结束后访问快照，避免项目锁与刷新回调互相等待。`DOCUMENT` 与 `PROJECT_FILE` 使用互斥字段；采用写入本次尝试检查点，交付引用采用版本。读取、采用和文档来源变化不递增任务输入版本；文档变化为消费者留下待复核事实。缺宿主当前内容核验的本地引用显示待确认。
- **141**：Agent 根据缺少成果、原因和依据建立或撤销自身关系，复用项目协调事务、图检查、输入失效和停止确认。幂等回执与重复关系不重复升版本；变更记录进入操作事实和执行检查点。批次外有效成果允许引用，缺失成果不扩张授权集合；新增业务目标按原批次与来源输入版本进入授权等待。
- **恢复行为**：原尝试停止确认后，可在有效批次下收回自身建立的精确关系，要求最新尝试、无未确认尝试、现存边及原 ADD 结果版本与当前版本一致。后续业务输入变化或关系重建时拒绝，不恢复项目文件写权限。相同目标阻塞不重复领取；业务输入变化或新批次重评。

## 入口

REST 宿主入口在 `/api/collaboration-host` 下，要求宿主 OAuth 身份与签名批次归属一致；MCP 复用 `CollaborationApiService` 的请求契约和领域服务。

| REST 路径 | MCP 操作 | 作用 |
| --- | --- | --- |
| `/documents/list` | `list_collaboration_documents` | 返回项目文档列表，结果为 documents 对象字段 |
| `/documents/read` | `read_collaboration_document` | 读取授权项目文档正文及来源版本 |
| `/attempts/adopt-context` | `adopt_collaboration_context` | 记录当前尝试的上下文采用 |
| `/attempts/dependencies/change` | `change_collaboration_dependency` | 记录成果判断、关系变更或目标授权请求 |

检查点和交付请求使用必填的 `contextRefs` 数组，没有采用来源时传空数组；不接受旧字段推断或别名。环境返回 `contextFacts` 与 `dependencyFacts`，任务详情返回上下文事实。
