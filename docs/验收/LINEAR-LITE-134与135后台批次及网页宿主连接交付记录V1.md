# LINEAR-LITE-134 与 135 后台批次及网页宿主连接交付记录 V1

日期：2026-11-10。

## 交付内容

| 任务 | 实现 |
|---|---|
| LINEAR-LITE-134 | 后台出站 HTTP 领取持久批次，按批次与项目根目录去重，复用执行池；依赖、资源及空查询维持等待；使用服务器固定截止时间与尝试消耗；停止、失联与预算耗尽进入停止确认及批次结束流程 |
| LINEAR-LITE-135 | 项目设置提供安装下载、浏览器设备授权、连接与授权状态、指定授权撤销、目录绑定及冻结批次停止入口；区分浏览器回环连接、服务器心跳、设备授权及目录校验结果 |

宿主启动扫描根锁、执行恢复关联与进程组记录。原宿主退出且登记组退出时，使用原批次能力凭据恢复；当前授权失效或待领取列表为空不阻止停止恢复。同进程断网恢复须由原执行池交出内存停止证明，驱动等待池返回并核对根锁归属后使用，不能用当前 PID 或活动列表为空替代停止事实。

执行池在停止确认前封存并排空写入能力，结束托管进程组，等待工具队列、心跳和停止请求；在途领取创建的写门参与收口。未知接受、创建结果不明、活跃进程组、证明或凭据缺失、根锁归属变化保留冻结。各项目根目录的批次收口按原批次 ID 隔离。

服务器从批次、任务输入、依赖、范围和执行尝试派生 `RUNNING`、`READY`、`RESOURCE_WAIT`、`DEPENDENCY_WAIT`、`BLOCKED`，保留生命周期、租约与停止事实的优先级。正常 `stop_requested` 展示停止中，租约失效展示待恢复。成果齐备不能替代宿主 `finish`；没有新增运行状态或检查点持久副本，没有新增数据库结构。

网页按目标授权 ID 向服务器提交撤销，不调用无参数的本机退出接口，避免并发重授权时撤销另一条授权。宿主心跳识别失效授权；撤销响应不代表执行退出或范围释放。目录变更受服务端冻结门禁约束，停止入口遍历批次分页并按当前绑定筛选，不提供解除冻结接口。用户、项目切换后丢弃旧响应，设备绑定沿用用户、项目、设备唯一记录，资料目录由项目根目录推导。

## 安装与分发

- 安装产物：[macOS Apple Silicon 宿主 V2](../交付产物/Linear-Lite协作宿主-macOS-arm64-V2.dmg)。V1 保留为历史产物。
- 适用环境：macOS 11 及以上、Apple Silicon；内含 Node.js 22.23.4 与许可证。
- 图形安装、连接、状态与卸载说明：[宿主安装与连接 V2](../开发指引/LINEAR-LITE-133-宿主安装与连接V2.md)。
- 实现契约：[后台批次控制 V1](../开发指引/LINEAR-LITE-134-后台批次控制V1.md)、[项目宿主连接 V1](../开发指引/LINEAR-LITE-135-项目宿主连接V1.md)。

网页经当前账号认证请求 `GET /api/collaboration/host-installer` 下载文件，不使用地址参数传递令牌。本机连接不接收网页登录令牌或 Cookie。安装包随服务版本进入非静态 classpath 目录 `host-distribution`，接口按资源流返回；构建检查指定 V2 产物，缺包不回退 V1，不增加服务器目录配置。

安装应用使用 ad-hoc 签名，未经过 Apple 公证，保留系统隔离标记；系统可能要求用户在应用安全设置确认打开。使用网页下载入口需要部署本轮服务端与前端，当前服务器未切换版本。

## 完成边界

两张任务卡的开发范围完成。真实图形安装、服务器账号授权、系统登录与睡眠恢复、真实模型批次及部署联调未执行；E2E 未执行：用户未显式调用。进程退出证明覆盖托管 app-server 与登记进程组，不证明主动脱离进程组的任意只读后代退出，业务写入仍受宿主封存门禁约束。

本轮不提交或推送，不部署、不启用定时任务，不修改方案文档、本机环境配置或用户已有改动。批次启动与状态网页属于 LINEAR-LITE-136，网页与后台宿主组合联调属于 LINEAR-LITE-137；本轮不宣称网页批次全流程完成。
