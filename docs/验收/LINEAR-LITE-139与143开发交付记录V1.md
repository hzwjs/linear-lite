## 交付结果

### LINEAR-LITE-139

- 从服务端模型、DTO、查询及业务门禁删除任务写入范围、执行持有范围、任务全局执行开关和预配置公共约定字段。
- 删除旧全量协作输入替换、范围扩张接口、路径重叠等待、路径资源投影和交付范围包含判断；实际产物相对路径校验保留，并覆盖 `changedPaths` 与 `artifactRefs`。
- 批次固定任务集合承载执行授权。协作参与判定覆盖批次成员、执行记录和依赖关系，排队任务受普通完成门禁及输入失效保护；普通任务保留业务完成行为。
- 启动请求由用户提供任务、绑定和时长；服务端生成 1 槽、`max(5, taskCount)` 次尝试预算，集合上限 200，超限拒绝。时长使用正值及纳秒换算技术上限；幂等重放保持原预算。
- 只读交付允许空改动与空文件引用，完成条件、结果及停止确认保持必需；条件证据引用数组不能为 null。
- 删除字段脚本归档至 `schema.sql`，独立脚本为 `docs/运行说明/部署脚本/20261110-LINEAR-LITE-139-删除旧协作配置.sql`；脚本留待后续通过 DBX 同一会话、指定目标库执行。

接口字段和后续消费要求见 [139 开发指引](../开发指引/LINEAR-LITE-139-批次授权与预算契约V2.md)。

### LINEAR-LITE-143

- 项目级受管编辑移除 `writeScopes` 门禁及无条件全文件截断写入，提供读取、创建、局部补丁、带读取依据的覆盖、删除、重命名及目录创建。
- 同物理根的 gate 共享单次操作队列；内容与目标身份核验和落盘位于操作段内，不形成任务级文件或目录占有权，各尝试保留各自封存状态。
- 编辑 CAS `version` 包含内容与物理身份，`contentVersion` 表达读取字节的内容版本，两者来自同次摘要且语义分开；同内容但目标被替换的旧编辑遭拒。
- 文件 I/O 由 macOS `sandbox-exec` 中的受信 Node helper 执行，保护项目外位置和宿主私有状态，清除启动注入环境，保留符号链接、别名与硬链接检查。
- helper 的单次操作上限为 30 秒，内部元数据复制使用固定 `/bin/cp -p` 及固定文件描述符，helper 和复制进程位于独立受管进程组；超时或异常后确认整组退出才释放操作段。对应 gate 封存，结果不明的持久操作记录保留，其他尝试在操作结束后保持运行资格。
- 操作事实关联尝试、Agent 和操作编号；记录不包含文件正文或执行凭据。内容替换保留现有所有者、权限、macOS ACL 和扩展属性；临时文件复制后恢复真实源 mode，关闭旧句柄后重开以核验写权限，禁止绕过源文件拒写 ACL。
- 原文件拒绝删除导致临时文件清理失败时，记录 `unknown` 与项目相对 `cleanupPaths`，封存该 gate，保留原文件和可追踪的待恢复事实；禁止吞掉清理失败或通过清除用户 ACL 继续操作。

API、事实格式及后续接线要求见 [143 开发指引](../开发指引/LINEAR-LITE-143-项目级受管编辑V1.md)。

宿主编辑 CAS 保证限定同一受管入口；可写命令和外部编辑器不享有该保证。沙箱探针支持本机所测目录交换时序，不宣称覆盖其他系统版本的全部恶意并发时序。

本轮没有部署、运行数据库脚本、安装或重启本机宿主、创建模型批次、启用定时任务、提交或推送 Git。方案文档、前端、服务器配置及已有无关工作区改动保持原状。
