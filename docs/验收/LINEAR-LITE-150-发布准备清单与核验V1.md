## 本地核验

- Vue 类型检查、网页构建、宿主来源校验及离线 Maven 打包通过。独立读取 JAR 验证应用启动清单、协议过滤器、网页入口、包内结构和宿主镜像。257 项包内摘要与实际文件一致，V3.0.1 与交付镜像及来源清单一致。
- 构建隔离快照移除数据库用户名及 JWT 密钥的固定默认值，运行使用服务器原有的外置 `MYSQL_USERNAME` 和 `JWT_SECRET`。工作区原源码和配置保留。包内保留公共配置模板，排除本机及生产私有配置。
- 静态比对 `schema.sql`、新结构增量和 139 删列脚本通过。正向增量补齐版本字段及协作表，四个旧字段只在结构预检、历史备份范围及删列核对中出现。
- 停止和回滚边界按现有批次服务、宿主安装器与 DBX 会话能力核对。旧协议停止、数据库停写、实际备份及隔离恢复需要目标环境证据。
