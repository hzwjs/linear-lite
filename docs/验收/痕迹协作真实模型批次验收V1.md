## 验收中发现的问题与修订

本轮包含诊断运行与修订后的完整复验；失败记录保留，不能将最终成功描述成首次运行通过。

1. 原实现关闭本地 Code Mode host，模型无法派发动态工具。宿主改为显式启用并核验该基础设施，MCP、应用、插件、hook 和原生多 Agent 等能力保持关闭。
2. 模型把可选 `blockedReason` 传为 `null`，原宿主将其转发给要求字符串或省略的接口，触发 400。宿主在本机校验两个可选文本字段，向模型返回修正提示；服务器契约保持原定义，不增加字段兼容。真实复验中模型修正输入并完成留痕。
3. 外层 `sandbox-exec` 与 Codex 原生只读 Seatbelt 嵌套，导致读取控制命令退出 71。宿主移除外层封套，使用原生单层只读，配置、线程、回合均保持只读和禁止审批；命令网络关闭，文件修改经过宿主写入门。没有改为全权限命令或添加降级路径。

修订涉及 `codex-host/src/app-server.mjs`、`pool.mjs` 和对应测试，服务器 Java/前端程序未在本轮改动。读取与配置说明见 [宿主契约 V2](../开发指引/LINEAR-LITE-122-Codex宿主使用与运行边界V2.md)，替代 V1 的执行边界说明。
