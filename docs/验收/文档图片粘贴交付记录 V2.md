# 文档图片粘贴交付记录 V2

日期：2026-10-04。此版本替代 V1 的图片失败处理与本地路径处理规则。

## 交付行为

粘贴图片时，根据来源路径尝试读取并上传。读取与上传完成后，在原位置写入引用 `imageAssetId` 的文档图片；任一阶段失败，在原位置写入来源路径的普通文本。删除原有失败提示、重试转存、上传替换与文件选择操作。

正文、标题、列表和表格保持粘贴流程。图片处理队列的并发上限为三个任务；删除占位、撤销粘贴、切换文档和关闭编辑器会取消对应任务，迟到结果不能回填正文。

| 来源 | 处理 |
| --- | --- |
| 公网 HTTP(S) | 后端下载并通过现有文档附件服务转存；失败写入原 URL 文本 |
| 站内路径、相对路径、file://、Windows 文件路径 | 浏览器尝试读取图片内容，读取与上传失败写入原路径文本 |
| data:、blob: | 浏览器读取后走文档附件分片上传；失败保留来源字符串 |
| 剪贴板图片 File | 使用文件内容上传；有来源路径时保留该路径，缺少路径时使用文件名作为失败文本 |
| 文档图片资源 | 以资源 ID 复制；失败写入剪贴板中的图片路径，缺少路径时写入资源身份文本 |

图片节点与剪贴板 File 有对应关系时，读取输入采用 File，来源路径保留为独立的导入上下文。失败结果使用普通段落文本，图片地址、任务状态与错误消息不进入图片块字段。

浏览器对电脑文件路径的读取存在权限限制；本次验收的 file:// 和 Windows 路径读取被浏览器拒绝，结果按需求保留路径文本。服务端图片导入的公网地址与权限守卫延续 V1。
