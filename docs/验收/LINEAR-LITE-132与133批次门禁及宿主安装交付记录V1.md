# LINEAR-LITE-132 与 133 批次门禁及宿主安装交付记录 V1

日期：2026-11-10。

## 交付范围

LINEAR-LITE-132 将签名凭据关联到持久批次。批次接受、续租、任务领取、检查点、成果提交核对用户、设备授权、项目绑定版本、宿主实例、执行代次、停止意图及租约。原子接受形成一个执行归属；旧实例、旧代次和批次外任务请求遭拒。REST 和 MCP 进入同一领域门禁，旧无状态签发和网页执行入口移除。

设备心跳、批次运行租约和任务写入租约分离；任务租约受批次租约与固定预算截止时间限制。停止意图与业务写入按事务锁序裁决。失联或结果不明保留冻结范围、物理根锁及恢复凭据，不因超时推断进程退出。

停止恢复使用原批次能力凭据，允许签名过期，核对原执行归属与领取证明。该通道提供停止请求、停止确认、未确认领取恢复和批次结束，不授予续租、检查点或成果写入权。宿主停止执行、确认各尝试、结束原批次后释放根锁与凭据；零尝试批次使用同一收口流程。

LINEAR-LITE-133 提供 macOS 图形安装入口、用户级 LaunchAgent、浏览器设备授权、state 与 PKCE 校验、钥匙串凭据轮换、心跳、状态和卸载入口。授权记录使用一个钥匙串项，配置保存站点来源。初始化、连接、撤销和取令牌等待同一个加载过程；关闭期间返回的旧凭据不能启动心跳或恢复在线。

安装器管理 `com.linearlite.codex-host` 对应的服务，使用现有设备状态目录。端口被外部进程占用时提供进程号与活动监视器入口；存在根锁或待恢复执行时阻止覆盖与卸载。安装替换失败时恢复原应用、配置和服务。

## 边界与后续

本轮不部署服务端或数据库，不执行真实模型批次，不启用定时任务，不提交或推送代码。LINEAR-LITE-132 复用 130、131 的表与字段，没有新增 DDL；使用安装包前需部署对应的授权与批次服务。

未执行真实图形安装、系统浏览器登录、登录后系统拉起、进程退出后系统拉起及睡眠恢复验收；这些运行行为的证据限于接口测试、安装器模拟与包内运行时检查。网页 E2E 未执行。

宿主后台轮询与批次驱动属于 LINEAR-LITE-134；任务授权、依赖和批次网页属于后续任务。本轮安装包提供身份、授权与心跳，网页启动批次的端到端流程尚未交付。

原有代码、本机配置及其他工作区改动保留，方案文档保持原状。
