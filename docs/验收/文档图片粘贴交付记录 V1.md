# 文档图片粘贴交付记录 V1

日期：2026-10-04

## 交付行为

混合文档粘贴时，正文、标题、列表和表格进入编辑器；图片按所在位置创建占位，并以三个任务的并发上限转存。图片失败保留来源段落，提供重试或上传替换。删除占位、撤销粘贴、切换文档和关闭编辑器会取消对应任务，迟到的结果不能回填正文。

| 图片来源 | 处理方式 |
| --- | --- |
| 公网 HTTP(S) | 展示会话预览，后端下载并通过现有附件服务生成文档图片资源 |
| 剪贴板 File | 有明确图片对应关系时，使用文件数据走文档附件分片上传 |
| data:、可读取的 blob: | 浏览器读取为 File，走文档附件分片上传 |
| 电脑路径、file://、失效或跨来源 blob: | 保留说明和图片位置，提供上传替换；路径不进入持久化正文 |
| Linear Lite 文档图片 | 使用资源 ID；跨文档复制失败不影响其他图片和正文 |

转存完成的正文图片采用 `documentImage.props.imageAssetId` 与 `caption`。图片地址由文档资源清单解析，预览 URL 和任务状态属于编辑会话。旧的外链整段拒绝路径与批量复制失败路径删除。

## 代码入口

| 职责 | 文件 |
| --- | --- |
| 粘贴入口与选区替换 | `src/components/BlockNoteEditorReact.tsx` |
| HTML/Markdown 图片识别、文件关联和占位生成 | `src/components/documentImagePaste.ts` |
| 会话预览、任务队列、失败操作与取消 | `src/components/documentImagePasteController.ts` |
| 文档 API 与资源注册 | `src/components/StructuredDocumentEditor.vue`、`src/services/api/documents.ts` |
| HTTP 导入接口 | `linear-lite-server/src/main/java/com/linearlite/server/controller/DocumentImageImportController.java` |
| 公网图片读取与附件转存 | `linear-lite-server/src/main/java/com/linearlite/server/service/DocumentRemoteImageService.java` |

`POST /api/project-documents/{documentId}/image-imports` 接收 `{ "url": "…" }`，返回现有附件 DTO。网络访问前检查文档权限，上传阶段复核权限。自定义 DNS 在连接建立时校验地址；重定向逐次校验。拒绝本机、内网、保留地址与非 HTTP(S) 协议，端口限定 80/443；图片大小上限 6 MiB、重定向上限三次，连接及读取空闲超时三秒，读取预算二十秒。格式从文件内容识别，支持 PNG、JPEG、GIF、BMP、WebP。

## 行为边界

浏览器无法凭文件路径读取电脑文件；剪贴板携带文件内容时可上传，缺少内容时需要选择文件。blob 必须能被当前页面读取。HTTP 来源需要后端访问条件，浏览器能预览的链接可能受远端登录、防盗链或网络限制而无法转存。

BlockNote 表格单元格不支持图片块，单元格保留来源说明或链接，图片块放在所属表格后。代码块内图片语法保持原文。

转存完成前刷新页面会结束会话预览和任务操作；未完成的占位以普通来源链接或说明保留，需重新粘贴图片或上传文件。转存完成的文档图片通过资源 ID 回显。

## 验收入口

测试服务入口：`linear-lite-server/src/test/java/com/linearlite/server/service/DocumentImagePasteAcceptanceServer.java`。验收页面：`docs/验收/文档图片粘贴验收.html`。

测试服务通过 Maven 的 test classpath 启动，端口使用 19081，参数启用存储并设置测试 JWT secret；不得接入生产数据库或对象存储。Vite 使用 `VITE_API_PROXY_TARGET=http://127.0.0.1:19081`，端口 15173。页面包含测试登录与验收数据，不属于产品路由。验收结束后关闭本次浏览器任务和测试服务。
