# HTML 文档实施与验收记录

日期：2026-10-03。交付范围：代码、相关测试、浏览器验收与数据库增量 SQL。

## 交付行为

- 项目文档增加 `HTML` 类型；文档树点击打开浏览器新页签，阅读页不带项目侧栏。新建入口、收藏和搜索按文档格式分派。
- HTML 页提供源码编辑、导入与替换 `.html/.htm` 文件、运行预览、保存、下载、历史查看与恢复。保存携带 `expectedVersion`；冲突保留本地草稿并提供下载和读取服务器版本入口。
- `content_format -> contentFormat` 声明 `BLOCKNOTE` 或 `HTML`；正文采用 `content -> content -> content`。文档类型不能变更，HTML 源码不进入 BlockNote 转换，快照保留格式与源码。
- 预览使用有项目权限检查的 POST 接口和 `sandbox="allow-scripts"` iframe。源码保持存储原文；jsoup 生成预览副本和搜索文本。预览脚本与主站 DOM、登录存储隔离，CSP 限制外部资源和联网请求。
- 单文件 UTF-8 HTML 上限 5 MiB；样式、脚本、图片和数据内嵌。文件导入保留 UTF-8 BOM、首尾空白与换行。下载输出当前源码。
- HTML 保存生成版本快照；历史恢复生成新版本。历史请求和文件读取的过期结果不能覆盖新选择或用户编辑。

## 浏览器证据

Ego 浏览器 TaskSpace 12，前端 `127.0.0.1:15173`，HTTP 验收服务 `127.0.0.1:19081`。

验收服务使用项目的 JWT 过滤器、项目成员权限检查、REST 控制器、文档命令/查询服务、版本快照服务和 HTML 解析器。数据库 mapper、成员行和事务管理器是内存替身；登录为测试夹具。

| 流程 | 观察结果 |
| --- | --- |
| 登录返回新建 HTML 地址 | 登录后进入原目标页面 |
| 保存前运行预览 | 计数按钮从 0 变为 1 |
| 脚本隔离 | 父页面和 localStorage 访问抛错；fetch 请求被 CSP 阻止 |
| 创建与源码编辑 | 创建 v1，源码保存生成 v2 |
| 文件替换与下载 | 替换生成 v3；下载文件与导入文件字节一致，包含 BOM |
| 历史查看与恢复 | 查看 v1，恢复生成 v4；刷新后内容保持，脚本可运行 |
| 文档树新页签 | 原项目页保留，新页签没有侧栏，`window.opener === null` |
| 保存冲突 | 服务端更新后旧页签保存返回 409，本地源码保持，保存按钮阻止重复提交 |
| 历史恢复冲突 | 返回 409，历史面板显示刷新提示 |
| 权限 | 不匹配的项目路由不渲染源码；非成员预览返回 403，无令牌返回 401 |
| 预览响应 | `text/html`、`no-store`、`nosniff`、CSP sandbox 响应头 |
| 手机布局 | 375px 宽度无横向溢出，按钮高度 44px，源码焦点可见，历史列表可滚动 |
