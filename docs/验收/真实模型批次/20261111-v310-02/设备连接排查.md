# 协作设备连接排查

日期：2026-11-11；任务：LINEAR-LITE-153；适用范围：本轮共享项目源码，宿主协议版本 3。

设备可用于协作执行的判断依据是：当前账号的目标设备具有有效授权、服务器心跳在线，以及目标项目的设备目录绑定匹配。网页的“本机浏览器连接”用于判断浏览器能否访问本机接口，不能替代服务器在线状态。连接与授权不创建任务批次，也不证明任务执行成功。

## 入口与状态来源

进入项目设置 → “项目目录绑定”，查看“本机浏览器连接”“本机授权状态”“账号设备”和“最近心跳”。使用“刷新”重读状态；页面以 5 秒间隔刷新本机状态和服务器授权列表，加载或操作期间跳过轮询。

| 观察项 | 数据来源与判断 | 使用边界 |
| --- | --- | --- |
| 本机浏览器连接：“可连接” | 网页读取 `http://127.0.0.1:9781/status`，响应通过协议和状态校验 | 说明本机接口可用；宿主连接状态可能为需要授权、离线或协议不匹配 |
| 本机浏览器连接：“连接受阻” | 本机状态读取失败；网页请求超时为 5 秒 | 查看错误原文；可能涉及服务、来源限制、浏览器权限、响应格式或旧协议，不能据此断言服务器离线 |
| 本机授权状态 | 本机 `/status` 的 `connection`、`userId` | 本机账号与网页账号不符时显示“其他账号”；协议不匹配提示优先展示 |
| 账号设备 | 当前网页登录账号读取 `GET /api/collaboration/hosts`，逐条展示授权记录 | 按设备 ID 和授权记录区分设备与历史授权，避免把其他设备的在线状态当成本机状态 |
| 服务器显示在线／离线 | 服务端根据授权撤销时间和心跳时间计算 `authorized`、`online` | 在线要求授权未撤销、心跳存在，且心跳不早于服务器当前时间减 90 秒；恰好 90 秒的边界算在线 |
| 最近心跳 | 服务端返回 UTC 时间，网页用浏览器本地时间格式展示 | 空值显示“—”；宿主按 30 秒间隔发送心跳，页面状态存在刷新间隔 |

## 按状态处理

| 状态或现象 | 判断 | 处理与恢复依据 |
| --- | --- | --- |
| 本机“在线”，目标授权“服务器显示在线” | 本机近期心跳成功，服务器认可该授权 | 核对网页账号、本机 `userId`、目标 `deviceId` 和授权记录；核对项目根目录绑定；以服务器受理批次的结果判断能否启动 |
| `AUTH_REQUIRED`／“需要授权” | 宿主没有可用授权记录，或授权请求被拒绝、记录失效 | 点击“连接宿主”，在系统浏览器确认目标账号与设备授权；回到页面核对服务器在线与最近心跳 |
| `CONNECTING`／“连接中” | 宿主初始化、授权或心跳处理处于连接阶段 | 完成浏览器授权；授权回调等待上限为 5 分钟；连接按钮在此状态禁用，观察状态与心跳变化 |
| `OFFLINE`／“离线” | 宿主到站点的请求、网络或心跳响应失败 | 检查电脑唤醒状态、网络和安装时的 HTTPS 站点来源；恢复网络后观察心跳。授权有效时，宿主心跳定时器承担重试 |
| 服务器离线，本机接口可连接 | 浏览器与宿主的回环链路可用，服务器不满足在线条件 | 核对授权是否撤销、心跳是否为空或超出 90 秒，以及设备 ID；检查宿主出站连接，不能以“可连接”替代在线 |
| 服务器在线，浏览器“连接受阻” | 服务器保有有效心跳，本机接口访问失败 | 检查本机宿主、9781 端口、站点来源和浏览器本地网络访问权限；服务器在线不证明当前浏览器能完成本机目录校验 |
| “其他账号” | 本机状态的非空 `userId` 与网页登录账号不同 | 确认目标网页账号，点击连接入口，在授权页确认账号。恢复依据是本机账号匹配且该账号目标授权在线 |
| 授权记录显示“授权失效” | 该授权记录失效，不能用于新领取 | 通过连接流程创建新授权，核对新授权记录；历史撤销记录不代表新授权失效 |
| `UPGRADE_REQUIRED`／“宿主与服务器协议不匹配” | 本机能响应，但宿主检测到服务器协议不匹配 | 使用当前站点“下载宿主（macOS）”入口安装匹配版本，检查宿主与服务器发布版本及协议标记，返回页面复核 |
| “本机协作宿主协议需要升级，请下载新版宿主” | 网页识别旧本机接口或协议响应 | 下载当前站点安装包并按安装说明处理；升级完成后检查本机状态、账号和服务器心跳 |
| “本机宿主状态无效”／“本机宿主响应无效” | 状态字段或 JSON 响应不符合网页契约 | 检查 9781 端口的服务归属和安装版本，保留脱敏错误原文；不能归类为授权成功 |

界面文案以 `src/i18n/messages/zh-CN.ts` 为准。“在线”来自一次成功心跳，网络中断后本机状态会在请求失败时转为离线；服务器在心跳过期后转为离线，两侧存在时间差。

## 本机连接受阻的检查顺序

1. 在目标电脑打开“Linear Lite 协作宿主”的状态入口，确认宿主运行。电脑睡眠、关机和断网影响心跳。安装器管理用户服务 `com.linearlite.codex-host`。
2. 检查端口 9781 的服务归属。其他进程占用时，安装说明提供活动监视器处理入口；保留原执行和恢复事实，不能用关闭页面推断进程退出。
3. 核对浏览器站点与宿主配置中的 `origin`。本机接口要求 Host 为 `127.0.0.1:9781`，Origin 与配置一致；域名、协议或端口变化会导致拒绝，错误码为 `ORIGIN_DENIED`。无 Origin 的手工请求不能替代网页连接检查。
4. 查看浏览器开发者工具中 `/status` 请求的错误、超时、来源限制或本地网络权限提示。权限排查属于操作检查，源码不证明用户浏览器的实际授权状态。
5. 回到“项目目录绑定”点击“刷新”，对照本机状态、服务器授权和心跳。服务器列表加载失败时，不能把读取失败当成“没有授权设备”。

本机接口不接受 Authorization 请求头，网页请求使用 `credentials: omit`；不要把网页登录令牌、Cookie 或宿主凭据复制到本机请求、日志或文档。

## 协议不匹配的两条路径

| 路径 | 当前实现 | 处理依据 |
| --- | --- | --- |
| 网页 → 本机宿主 | 网页要求 `protocolVersion: 3`。具有设备 ID 的成功响应缺少该字段或版本不等于 3，或接口返回 404 且错误码为 `ROUTE_NOT_FOUND`，网页提示下载新版宿主；此时本机状态读取失败，页面可能显示“连接受阻” | 结合升级提示判断，不能把此现象归为宿主未启动 |
| 宿主 → 服务器 | 宿主 API 前缀为 `/api/collaboration-host/v3`；检查响应头 `X-Linear-Lite-Host-Protocol: 3`。HTTP 426，或成功／404 响应缺少匹配协议头，判为协议不匹配；心跳路径将状态写为 `UPGRADE_REQUIRED` | 检查宿主、服务器版本和网关是否保留协议响应头；页面隐藏该状态的连接按钮，保留下载入口 |

服务端 `HostProtocolFilter` 对旧宿主路径返回 HTTP 426 及升级提示。协议版本、安装说明文档版本和 DMG 文件名中的版本号是不同概念；不能因安装说明为 V2 而将宿主协议解释为 2。安装与连接不会修复服务器或网关的发布错配，恢复须以实际状态与协议响应为依据。

## 项目目录与停止边界

在目标电脑选择本机设备并填写项目绝对路径，保存前由宿主核对设备、目录存在性、访问能力与规范路径；服务端保存当前用户、项目和设备的绑定。其他设备绑定采用只读展示，资料目录从项目根目录推导为 `docs/`。设备在线不代表绑定存在或目录校验通过。

“重新授权”和“撤销授权”影响关联批次：重授权替换同账号、同设备的旧授权，旧授权关联批次接收停止意图；网页撤销针对选中授权 ID。撤销成功不证明执行进程退出、范围释放或目录解冻。目录保存／删除受阻时，按页面列出的关联批次提交停止，等待原宿主停止确认；缺少恢复资料时保留冻结，不通过清理设备身份、根锁或凭据绕过检查。安装器遇到根锁或待恢复执行时可能阻止替换，按宿主安装说明处理。
