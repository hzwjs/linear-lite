# 网页协作执行操作说明

日期：2026-11-11；任务：LINEAR-LITE-154；适用范围：本轮共享项目实现，宿主协议版本 3。

操作路径：核对设备与目录 → 在项目任务列表勾选任务 → 启动协作批次 → 查看批次与任务成果。

## 1. 判断设备是否可用

打开目标项目设置的“项目目录绑定”，点击“刷新”，核对目标设备、账号、授权、服务器在线状态和项目目录。采用本轮 LINEAR-LITE-153 形成的 [设备连接排查](设备连接排查.md)，项目相对路径为 `docs/验收/真实模型批次/20261111-v310-02/设备连接排查.md`。

| 网页观察 | 判断与操作 |
| --- | --- |
| 目标设备授权有效，显示“服务器显示在线”，存在目标项目目录绑定 | 满足网页设备选项的启用条件；启动受服务器校验约束。核对设备 ID、网页登录账号和目录，避免选择其他设备 |
| 本机浏览器连接显示“可连接” | 表示网页能访问本机宿主接口；执行可用性须结合服务器授权、心跳和目录判断 |
| “需要授权”或“授权失效” | 使用“连接宿主”完成浏览器账号授权；回到页面核对目标授权和心跳 |
| “离线”或“服务器显示离线” | 检查目标电脑运行、网络与宿主出站连接；参照设备排查文档恢复心跳，返回执行页点击“刷新” |
| “连接受阻”，服务器显示在线 | 排查本机服务、9781 端口、站点来源和浏览器本地网络权限；本机目录校验可能受阻，不能据此认定服务器离线 |
| “其他账号” | 核对网页账号与本机授权账号，按设备排查文档处理重授权 |
| “宿主与服务器协议不匹配”或下载新版提示 | 使用当前站点“下载宿主（macOS）”入口，按设备排查文档检查宿主、服务器和协议；本轮协议为 3 |

服务器在线依据是授权未撤销、存在心跳，且心跳不早于服务器当前时间减 90 秒；宿主心跳间隔为 30 秒。设备状态与网页刷新存在时间差，在线状态不保证下一次启动成功。

本机目录使用项目根目录绝对路径，保存经过宿主校验；协作资料目录由项目根目录推导为 `docs/`。本机可连接、设备在线、目录绑定是三个判断项。远端设备应由目标电脑完成连接与目录绑定，本机回环状态属于浏览器所在电脑。

## 2. 准备并选择任务

1. 打开目标项目的任务列表。为任务写明需求、产出路径和完成条件。
2. 选择状态为 `todo`、没有子任务的叶子任务；前置任务须属于同一项目且为叶子任务。父任务、其他状态和失效配置会被服务器拒绝。
3. 将鼠标移到任务行，在行首复选框勾选目标任务；勾选后页面底部显示批量操作栏。
4. 点击“启动协作批次”，进入该项目“协作执行”页，检查“所选任务”的编号与标题。点击任务可进入任务详情。

一次启动支持 1 至 200 项任务，任务集合在启动时固定。前置成果未就绪时，批次可以进入依赖等待；启动受理不表示每项任务具备领取条件。需要查看前置和执行事实时，打开任务详情中的“协作事实”。

## 3. 启动批次

1. 在“执行设备”选择目标设备与项目目录。下拉选项来自当前账号的项目目录绑定；缺少有效授权或服务器离线的选项禁用。缺少可用选项时，点击“设备与目录设置”处理，返回执行页点击“刷新”。
2. 填写“运行时长上限（小时）”。初始值为 1 小时，输入须大于零且能表示为整数毫秒；服务器检查可接受范围。
3. 核对所选任务、执行设备、项目目录和时长，点击“确认启动”。任务不可读取、设备不可用、时长无效或页面加载期间，按钮禁用。
4. 成功响应后，页面进入对应批次详情。核对“批次历史”和“批次详情”，观察状态从“等待领取”到执行或等待状态的变化。

网页负责选择设备、任务和时长；并发数与尝试预算由服务器分配，详情展示实际值。当前实现并发数为 1，尝试预算为任务数与 5 的较大值。开始时间与截止时间在宿主接受批次时确定，运行时长不是完成承诺。

服务器返回“任务状态不允许领取”“协作执行要求叶子任务”或“项目目录绑定版本已变化”等错误时，依据错误核对任务与绑定；通过页面“刷新”和下节的待确认流程确认启动结果。

## 4. 启动结果待确认

网页在发送请求前，将本次启动请求保存到当前浏览器存储，按账号与项目区分。网络中断、响应丢失或刷新后可能显示“上次启动结果待确认”。

| 入口或提示 | 操作与含义 |
| --- | --- |
| “重试上次启动” | 发送原操作标识与原参数，用于查询或完成原启动；待确认面板展示原任务、设备绑定和时长 |
| “放弃重试” | 清除浏览器的待确认记录；不会取消服务器可能创建的批次。查看批次历史，确认原批次状态后决定后续操作 |
| “无法保存启动请求，请检查浏览器存储权限” | 处理浏览器存储权限；保存失败时本次请求未发出 |
| “保存的启动请求无法读取” | 查看批次历史并确认服务器事实，按页面确认流程处理“放弃重试”；不要把本地记录损坏解释为服务器没有批次 |

需要停止存在的批次时，在该批次详情点击“停止批次”。“取消”用于离开新启动表单；“放弃重试”用于清除待确认记录，两者不能替代停止批次。

## 5. 查看状态和成果

从项目侧栏进入“协作执行”，在“批次历史”选择批次；历史超出当前页时点击“加载更多”。页面以 5 秒间隔刷新历史和当前详情。“刷新”重读任务、设备、目录和批次；设备恢复后使用此按钮更新启动选项。

详情展示执行设备、项目目录、并发数、时长上限、尝试次数、开始时间、截止时间和结束原因。目录显示“目录绑定发生变化”时，当前绑定无法对应批次记录的版本，不应把新目录当作原执行目录。

| 批次状态文案 | 含义与处理 |
| --- | --- |
| 等待领取 | 服务器创建批次，等待目标宿主接受；核对设备心跳与连接 |
| 等待执行 | 存在可执行任务，或成果齐备等待宿主结束批次；查看任务事实判断进度 |
| 执行中 | 批次存在运行中的任务尝试；查看检查点、发现和产物引用 |
| 等待任务执行 | 任务存在未确认停止的活动尝试；查看关联执行，避免重复启动 |
| 等待依赖 | 查看任务的输入等待原因及“协作发现”，确认前置材料和成果 |
| 等待成果变化 | 复核要求材料变化；查看“成果复核”的发现、依据与产物状态 |
| 等待目标授权 | 查看“新增业务目标”及“影响”；决定是否点击“授权执行”，确认后创建新批次，“查看新批次”用于进入结果 |
| 等待停止确认／停止中 | 存在停止意图或待确认的任务执行，等待宿主完成停止确认 |
| 待恢复 | 批次或尝试租约失效、执行状态缺少停止确认等；保留原宿主运行与恢复材料，按设备排查文档处理连接和恢复 |
| 预算耗尽 | 时长或尝试预算达到上限；查看交付成果与结束原因，不等同于所有任务失败 |
| 受阻 | 查看任务输入、配置、成果和阻塞事实；按错误依据处理 |
| 已结束 | 结合结束原因判断完成、用户停止、预算耗尽或需要处理；不能以结束状态替代成果验收 |

批次详情中的任务区和任务详情的“协作事实”提供以下依据：

- “采用的资料”：文档或项目文件与确认状态；“待确认”“待复核”不能当作材料通过。
- “协作发现”“成果复核”：缺项、关系变更、采用、任务内修补、等待变化、返工及目标授权事实。
- “检查点”：记录时间、发现、阻塞原因和产物引用。
- “交付成果”：每项完成条件、执行结果、证据引用、修改路径和产物引用。
- 尝试状态与“停止确认时间”：区分“执行中”“交付成功”“失败”“等待停止确认”和“租约失效，待恢复”。

验收任务时，核对完成条件与证据，读取引用成果，并查看未完成项。网页状态展示、设备在线和编译通过属于不同证据，不能替代业务成果判断。页面加载失败或出现未知状态时，保留错误原文，点击“刷新”或“重试”；读取失败不代表批次不存在或执行结束。

## 6. 停止与恢复

在批次详情点击“停止批次”并确认，观察停止状态与任务“停止确认时间”。停止请求成功表示服务器记录停止意图；进程退出、编辑入口封存和范围释放依赖宿主确认。关闭或刷新网页不会停止批次。

设备离线或“待恢复”期间保留原宿主及其恢复材料。不要通过删除身份、凭据、根锁或更换目录绕过冻结。重授权或撤销设备授权会影响关联批次，操作影响及目录冻结处理采用 [设备连接排查](设备连接排查.md)。项目目录保存或删除受阻时，在“项目目录绑定”查看关联批次并提交停止，等待原宿主确认。
